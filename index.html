GDT Assistant — an unofficial, fan-made, fully-offline companion for Game Dev Tycoon. Fit ratings use the game's own pairing values (Great 1.0 · Good 0.9 · Okay 0.8 · Bad 0.7 · Terrible 0.6); recommendations rank by combo fit (topic↔genre dominant), tie-broken by an estimated sales reach. Great combinations are badged; clearly bad combos are never recommended.
